# Weather Starter Themes

This document records the visual theme directions proposed for Weather Starter and the main design choices discussed for each. Themes change presentation only; weather data, saved locations, map interactions, location creation, refresh behavior, and the backend API stay the same.

## Shared design considerations

- Keep temperature and weather condition prominent, with clear hierarchy for location, observation time, and forecast details.
- Preserve readable contrast across the location sidebar, hero, map labels, hourly strip, daily forecast, metric cards, and controls.
- Keep numeric weather readings aligned and easy to compare; use tabular numerals where available.
- Retain the existing location, search, add-location, selection, delete, refresh, and map flows in every theme.
- Ensure theme colors also work for input fields, focus indicators, selected locations, chart scales, error states, and the theme selector.
- Keep the layout usable at narrow viewport widths; density choices should not hide essential readings or force page-wide horizontal scrolling.
- Give map labels and pins enough contrast against the unchanged map tiles.

## Selector names

The selector currently stores theme identifiers in local storage. The implemented theme identifiers are `apple`, `clear-skies`, `monsoon-radar`, `singapore-morning`, `coastal`, `paper`, `midnight`, and `alpine-forecast`. “Coastal” is the shortened selector label for the proposed **Coastal Breeze** direction; “Midnight” and “Paper” similarly abbreviate **Midnight Observatory** and **Paper Almanac**.
